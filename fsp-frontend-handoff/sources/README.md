All names, contacts, repository examples and salaries in them are demonstration content. The per-image manifest records the selected file and checksum.

The actual technical specification states that the FSP API, data schema and datasets are intentionally not supplied. The earlier announcement's different resource description is not used as evidence of an available integration.

The package does not contain an authenticated GitHub repository snapshot, a live FSP dataset, model credentials or the user's VM configuration. The repository URL in the conversation identifies the intended destination; its current code state must be inspected by the implementing agent.

The user requested GitHub-first automatic enrichment, Rust backend, React/TanStack/FSD frontend, a modular repository, named branches merging through `dev`, and `main` deployment. Subsequent design decisions distinguish anonymous employer views, company-scoped contact consent and AI-permitted assessments. These are product decisions, not claims extracted from the organizer PDF.

The working palette and wordmark are a proposed interface direction. A separate official logo asset/complete brandbook was not validated as part of this frontend package. Do not trace a generated raster logo and label it an official vector asset. Preserve the reference palette and replace the wordmark with an authorized supplied asset when available.
