# Выготский

«Выготский» — отраслевая платформа обратного подбора для ИТ. Она превращает
подтверждённые результаты соревнований в граф компетенций, помогает работодателю
найти кандидата под требования вакансии, а кандидату — увидеть пробелы и выбрать
соревнования, которыми их можно закрыть.

Публичное демо: <http://93.77.179.211:8010> ·
[OpenAPI](http://93.77.179.211:8010/docs)

Артефакты сдачи: [презентация](output/Выготский_ФСП_2026.pptx),
[техническая документация](output/Выготский_техническая_документация.pdf) и
[полная матрица требований](docs/requirements-traceability.md).

## Что уже работает

- регистрация с подтверждением email, вход и два изолированных ролевых кабинета;
- профиль кандидата вручную, связь с FSP ID и стандартизированный PDF;
- вариативный тест грейда с историей попыток и 90-дневным cooldown;
- профиль кандидата из тестов и результатов ФСП, Codeforces и хакатонов;
- граф навыков с уровнем и уверенностью для каждого доказательства;
- автоматические категории специализации;
- вакансии с уровнем и критичностью требований;
- политика доверия рейтингу платформы или списку соревнований работодателя;
- объяснимый рейтинг кандидатов, пробелы и рекомендации соревнований;
- персональное приглашение с зарплатной вилкой, в том числе без вакансии;
- вакансии, отклики, статусы и раскрытие контакта только по согласию кандидата;
- интерактивные режимы работодателя и кандидата;
- версионированный API и идемпотентная синхронизация ФСП.

Все предзаполненные профили, компании, соревнования и результаты в текущем deployment —
демонстрационные данные. Формат ФСП реализован по структуре из задания и
заменяется официальной спецификацией без изменения доменного алгоритма.

Публичная витрина специально остаётся демонстрационной: она объясняет продукт
без регистрации. Кнопка «Войти» открывает рабочий контур; созданные аккаунты,
профили, тесты, вакансии, приглашения и отклики сохраняются в БД.

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pip install --no-deps -e .
.venv/bin/uvicorn app.main:app --reload
```

Интерфейс: <http://127.0.0.1:8000>. Интерактивная документация API:
<http://127.0.0.1:8000/docs>.

По умолчанию подтверждение email работает в явном `demo-outbox` и возвращает
код в ответе регистрации. Для реальной отправки задайте
`VYGOTSKY_DEMO_AUTH=0`, `VYGOTSKY_SMTP_HOST`, `VYGOTSKY_SMTP_PORT`,
`VYGOTSKY_SMTP_USERNAME`, `VYGOTSKY_SMTP_PASSWORD` и `VYGOTSKY_SMTP_FROM`.
Импорт ФСП отключён, пока не задан `VYGOTSKY_INTEGRATION_KEY`; клиент передаёт
его в заголовке `X-Integration-Key`.

## Основные маршруты

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/v1/candidates` | Профили и фильтры специализации, грейда, стека и ФСП |
| `GET` | `/api/v1/candidates/{id}` | Доказательства, граф, мэтч и рекомендации |
| `GET` | `/api/v1/vacancies/{id}/matches` | Обратный подбор и объяснение оценки |
| `POST` | `/api/v1/vacancies` | Граф требований вакансии |
| `POST` | `/api/v1/invitations` | Приватное приглашение кандидату с зарплатой |
| `POST` | `/api/v1/applications` | Отклик на опубликованную вакансию |
| `POST` | `/api/v1/integrations/fsp/sync` | Защищённый атомарный импорт пакета ФСП |

MVP использует локальные аккаунты, хэшированные пароли, подтверждение email,
серверные сессии и ролевую модель. Для промышленной федерации учётных записей
описана граница OIDC/Keycloak; проверка юридического лица остаётся процедурой
эксплуатации, а не фиктивной автоматизацией в демо.
