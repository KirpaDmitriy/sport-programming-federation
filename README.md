# Контур

«Контур» — отраслевой сервис обратного подбора для ИТ. Он превращает
подтверждённые результаты соревнований в граф компетенций, помогает работодателю
найти кандидата под требования вакансии, а кандидату — увидеть пробелы и выбрать
соревнования, которыми их можно закрыть.

Проект находится в активной разработке. Границы MVP и критерии готовности
зафиксированы в [docs/product-scope.md](docs/product-scope.md), архитектурное
решение — в [docs/architecture.md](docs/architecture.md).
