# Контракт интеграции ФСП

MVP принимает пакет через `POST /api/v1/integrations/fsp/sync`. Маршрут закрыт
секретом `VYGOTSKY_INTEGRATION_KEY`, который передаётся в заголовке
`X-Integration-Key`; без настроенного секрета интеграция отвечает `503`. Полная схема,
ограничения полей и интерактивный пример доступны в `/docs`; сохранённая версия
находится в `docs/openapi.json`.

## Структура пакета

```json
{
  "disciplines": [
    {"id": "algo", "name": "Алгоритмическое программирование"}
  ],
  "participants": [
    {
      "id": "person-42",
      "name": "Участник",
      "city": "Москва",
      "work_format": "remote",
      "desired_role": "Backend-разработчик",
      "stack": ["Python", "C++"]
    }
  ],
  "competitions": [
    {
      "id": "cup-2026",
      "name": "Кубок 2026",
      "discipline_id": "algo",
      "participants": 640,
      "difficulty": 0.9,
      "official": true,
      "skills": {"algorithms": 1.0, "python": 0.5}
    }
  ],
  "results": [
    {
      "id": "result-9001",
      "participant_id": "person-42",
      "competition_id": "cup-2026",
      "placement": 3,
      "participants": 640,
      "role": "captain",
      "rank": "КМС"
    }
  ]
}
```

`difficulty` и значения `skills` лежат в диапазоне 0–1. `skills` — результат
предметного сопоставления соревнования с каталогом компетенций, а не оценка
конкретного участника.

## Гарантии импорта

- внешний результат уникален по паре `source + external_id`;
- повтор одного пакета обновляет существующие записи без дублей;
- ссылки результата на участника и соревнование проверяются до записи;
- неизвестная дисциплина или компетенция отклоняет пакет;
- пакет применяется одной транзакцией: ошибка не оставляет частичные данные;
- синхронизация не требует GPU, модели или доступа в интернет.

Когда организаторы предоставят официальный транспорт, его ответ преобразуется
в этот пакет на границе `infrastructure`; формула профиля и API продукта при
этом не меняются.

Обновлённое ТЗ не предоставляет официальный API, структуру реестра или датасет.
Поэтому этот контракт — явно маркированная синтетическая граница MVP, а не
заявление о доступе к производственным данным ФСП. Профиль без `fsp_id` и без
истории результатов проходит тот же тестовый и матчинг-контур.
