# Проверка поставки

Статус фиксируется по наблюдаемому доказательству, а не по наличию файла.

## Продукт

- [x] Работодатель выбирает вакансию и получает ранжированных кандидатов.
- [x] Категории кандидата вычисляются из подтверждённых результатов.
- [x] Профиль показывает уровень, уверенность и исходные доказательства.
- [x] Граф показывает зависимости компетенций.
- [x] Редактор вакансии принимает несколько навыков, уровни и критичность.
- [x] Работодатель выбирает рейтинг платформы или список соревнований.
- [x] Разность графов показывает дефициты и критичные пробелы.
- [x] Кандидат получает рекомендации будущих соревнований.
- [x] Предложение содержит вакансию, сообщение и зарплатную вилку.
- [x] Пакет ФСП содержит дисциплины, соревнования, результаты, роли и разряды.
- [x] Импорт идемпотентен, атомарен и проверяет ссылки.

## Инженерная поставка

- [x] Приватный GitHub-репозиторий и гранулярная история коммитов.
- [x] OpenAPI и отдельное описание контракта ФСП.
- [x] Инструкция, unit systemd и production smoke-скрипт.
- [x] Доменный, persistence, контрактный и API-наборы тестов.
- [x] Offline CPU smoke без внешней модели и сети.
- [x] Реестр алгоритмических экспериментов и JUnit-артефакты.
- [x] GitHub Actions выполняет тесты, smoke и проверку экспериментов.
- [x] Read-only аудит существующего MetroGuard на ВМ.
- [x] Отдельный `kontur-talent.service` active на ВМ.
- [x] Публичный URL отвечает и проходит `deploy/smoke.sh`.

## Визуальное и архитектурное ревью

- [x] Яркая собственная система цветов, типографики, форм и движения.
- [x] Два режима интерфейса и адаптивные правила для 980/700 px.
- [x] `prefers-reduced-motion`, подписи форм и доступные имена контролов.
- [x] Внешние строки экранируются перед вставкой в HTML/SVG.
- [x] Нет широких `except`, молчаливых fallback и необоснованных suppressions.
- [x] Доменный слой не импортирует HTTP или SQLite.
- [x] В реализации нет параллельных путей расчёта мэтчинга.
- [ ] Desktop/mobile render проверен скриншотами без переполнений.
