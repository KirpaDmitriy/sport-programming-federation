# Organizer source

[`organizer-spec.pdf`](organizer-spec.pdf) is the organizer's specification for the FSP special track («ФСП спец.
трек ТЗ»), supplied by the team: nine physical pages, a cover and printed pages 1–8.
[`../REQUIREMENTS_TRACEABILITY.md`](../REQUIREMENTS_TRACEABILITY.md) cites it by printed page number.

The specification states that no FSP API, data schema or datasets are supplied. Every FSP record in the platform is
synthetic.
